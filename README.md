# 源氏：军刀与飞刀

强化《绝地潜兵 2》的 **CQC-2 礼仪军刀**与**投掷飞刀**。

## 改动

### CQC-2 礼仪军刀

| 项目 | 原版 | 修改后 |
|---|---|---|
| 直击伤害 | 188 | **600** |
| 耐久伤害 | 98 | **300** |
| 穿甲 | AP3 | **AP4（重甲穿透）** |
| 挥砍间隔 | 0.03 秒 | **0.0075 秒** |

此外，持刀时本机角色的动画速度提升至 **×1.3**。原有攻击动作与判定范围保持不变。

### 投掷飞刀

携带上限、初始数量与两种补给回复量均已上调：

| 项目 | 原版 | 修改后 |
|---|---|---|
| 携带上限 | 20 | **30** |
| 初始数量 | 10 | **15** |
| 补给回复量（一） | 20 | **30** |
| 补给回复量（二） | 20 | **30** |

## 依赖

**只需要 Bingus Shared Loader v15 及以上**（或兼容的新版本）。无其他前置，下载即用。

## 安装

把 ZIP 导入 Arsenal / HD2 Mod Manager，启用后部署，彻底退出游戏再重新启动。
Loader 放到列表最后（若开启「首个 mod 优先」则放最前）。

## 版本与适配

- 当前版本：`0.1.4`（实验性）
- 目标游戏构建：**25327279**

本 mod **不校验游戏构建号**，改为在写入前逐字段核对原始字节：一旦游戏数据不匹配，会返回 `record_mismatch` / `field_mismatch` 并**直接拒绝写入**，不会强行覆盖。

游戏更新后可能失效，届时需要重新适配。

## 日志

```
%LOCALAPPDATA%/CowboyBingus/Helldivers2/Logs/GenjiThreefold.log
```

排查时先看日志中的 `field_mismatch`、`record_mismatch`、`saber_speed_*` 等标记。

## 注意

内存模组属客户端运行时改动，联机表现可能与队友不一致，并存在反作弊风险。建议仅在知情固定队环境中使用。
